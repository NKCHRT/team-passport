# Интеграция «Паспорт команды» с сайтом ПГФВ

Приложение можно разместить на сайте федерации рядом с разделом «Команды». Тогда данные страницы команды читаются **без CORS-ограничений**: приложение и сайт находятся на одном домене.

> Пошаговая инструкция для WordPress — в `WORDPRESS-INTEGRATION.md` и в файле «Интеграция с сайтом ПГФВ.docx».

## Вариант 1. Кнопка-ссылка на страницу команды

Самый простой способ. На странице команды (шаблон `tpl-team-item.php` или карточка команды) добавьте ссылку:

```php
<a class="button button--passport"
   href="/team-passport/?teamUrl=<?php echo urlencode(get_permalink()); ?>">
   Создать паспорт
</a>
```

Приложение откроется, прочитает переданный URL, разберёт карточки игроков и загрузит фотографии.

- `/team-passport/` замените на фактический путь, куда распаковано приложение.
- Ссылка должна быть абсолютной (`https://perm-volley.ru/...`), `get_permalink()` это обеспечивает.
- Страница должна быть именно страницей команды, а не списком групп: на ней должны быть блоки `.playerCard__item`.

## Вариант 2. Встроить приложение в iframe и передать данные

Если на странице команды уже есть готовые данные (например, из того же шаблона), можно не парсить HTML, а передать JSON напрямую:

```html
<iframe id="teampass" src="/team-passport/" style="width:100%;height:900px;border:0"></iframe>

<script>
  const team = {
    teamName: "Демо-команда 2027",
    season: "СЕЗОН 26/27",
    players: [
      { name: "Иванов Иван", birth: "15.08.1997", number: "1", position: "Либеро",
        photo: "https://perm-volley.ru/wp-content/uploads/.../photo.jpg" }
    ]
  };

  document.getElementById("teampass").contentWindow.postMessage(
    { type: "teampass:import", payload: team },
    location.origin
  );
</script>
```

Приложение принимает сообщения с `type: "teampass:import"` и объектом `payload`.

### Формат payload

```js
{
  team: {
    name: "Демо-команда 2027",       // или teamName на верхнем уровне
    season: "СЕЗОН 26/27",           // необязательно
    accent: "#D9251C",               // необязательно
    logo: "data:image/png;base64,…"  // необязательно, логотип команды
  },
  players: [
    {
      name: "Иванов Иван",            // обязательно
      birth: "12.03.2001",           // необязательно
      number: "1",                   // необязательно
      position: "Либеро",            // необязательно
      captain: true,                 // необязательно, капитан команды
      photo: "https://…/photo.jpg"   // URL или data:image/…
    }
  ]
}
```

- Если `photo` — URL, приложение попробует загрузить его напрямую (на сайте это работает), а при ошибке — через CORS-прокси.
- Если `photo` — `data:image/jpeg;base64,…`, оно используется как есть.
- Максимум — 60 игроков; на лист A4 помещается 18, остальные автоматически уходят на следующие листы.
- Если `number` и `position` не переданы, поля останутся пустыми — их можно заполнить в приложении.

## Вариант 3. Данные в ссылке (без iframe)

Можно передать JSON, закодированный в base64:

```php
<?php
$payload = [
  'teamName' => get_the_title(),
  'players'  => $players, // массив с name/birth/photo
];
$encoded = rtrim(strtr(base64_encode(json_encode($payload, JSON_UNESCAPED_UNICODE)), '+/', '-_'), '=');
?>
<a href="/team-passport/?teamData=<?php echo urlencode($encoded); ?>">Создать паспорт</a>
```

Приложение само разберёт `teamData` и применит данные. Для больших составов с фотографиями ссылка может быть длинной — лучше использовать вариант 2.

## Публичный JavaScript API

После загрузки приложения доступен объект:

```js
TeamPass.importTeamData(payload, { photos: true })
  .then(result => console.log(result.players))
  .catch(console.error);

// То же самое:
TeamPass.importTeam(payload);
```

`TeamPass.state` — текущее состояние проекта, `TeamPass.render()` — перерисовать лист.

## Как разбирается страница команды

Парсер (`js/site-import.js`) ищет:

- название команды — `<h1>`;
- логотип команды — featured image записи `teams` через REST API (`featured_media` → `source_url`);
- игроков — `.playerCard__item`;
- имя — `.playerCard__name`;
- дату рождения — `.playerCard__bday`;
- фото — `.playerCard__img img` (`src` / `data-src` / `srcset`);
- если карточек нет, пробуется табличный вид (`table tr` + дата).

Фотографии с суффиксом размера (`-225x300.jpg`) заменяются на полноразмерные (`Bazanov.jpg`), если такие доступны.

## Локальный режим и CORS

Если открыть `index.html` как файл, браузер блокирует чтение чужого сайта. Поэтому запускайте приложение через **`Открыть паспорт команды.bat`**: он стартует `server.py` на `http://127.0.0.1:8777/` и проксирует страницы и фотографии ПГФВ через `/api/proxy`. В этом режиме ссылка на команду работает так же, как на сайте.

Если Python недоступен, `.bat` откроет `index.html` без сервера. Тогда остаётся резервный импорт:

1. Откройте страницу команды на сайте.
2. Сохраните её через **Ctrl+S** (HTML).
3. В приложении: **Импорт с сайта ПГФВ → Выбрать HTML-файл**.

В этом резервном режиме фото загружаются через публичный CORS-прокси `wsrv.nl`; на сайте ПГФВ и через локальный сервер запросы идут напрямую.

## Безопасность

- Локальный сервер слушает только `127.0.0.1` и проксирует только `perm-volley.ru`.
- Приложение не отправляет данные на сторонние сервисы, кроме резервной загрузки фото через `wsrv.nl`, если локальный сервер недоступен.
- `postMessage` принимается только с того же origin или с домена `perm-volley.ru`.
- Все данные хранятся в браузере пользователя (`localStorage`).
